[ota-061][Validacion corregida]
Esta version corrige el rechazo de archivos de version validos. Con el lector y GitHub en 0.6.1 aparece Firmware al dia; Instalar se ofrece para una version posterior.

[interfaz-060][Nueva interfaz]
La opcion seleccionada queda rellena. El sobre del menu muestra cuantos avisos quedan sin leer.

[wifi-060][Un solo QR]
Primero conecta tu celular a la red y clave que muestra el lector. Luego escanea el QR para abrir directamente la pagina indicada.

[paginas-060][Prueba de paginas]
Este mensaje tiene varias paginas para probar los botones. El boton RECORRER pasa directamente a la pagina siguiente. Cuando llegas al final, vuelve a la primera pagina.
El boton CONFIRMAR vuelve directamente a la bandeja, desde cualquier pagina. Las dos funciones aparecen en la barra inferior sin ninguna opcion seleccionada.
Al volver, este aviso queda marcado como leido y baja el contador del sobre. Reiniciar el lector conserva esa marca.

[calibracion-060][Factor de expansion]
Sin calibrar gotas significa que todavia se miden diametros de manchas. El factor permite estimar diametros de gotas; no se elige automaticamente por tipo de producto.
